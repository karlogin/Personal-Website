# Product Overview

Personal portfolio website for Karthik Padmanabhan, a game developer and designer with experience at Gameloft and other studios.

## Purpose

- Showcase professional experience and technical skills in game development
- Display portfolio of shipped games and projects
- Provide contact information and links to professional profiles
- Serve as a personal brand presence on the web

## Key Features

- Single-page responsive design
- Professional portfolio with project listings
- Social media integration (Twitter, LinkedIn, email)
- Google Analytics tracking
- Mobile-optimized with PWA manifest
- SEO optimized with sitemap and meta tags

## Target Audience

Game industry recruiters, potential employers, collaborators, and professional contacts.
